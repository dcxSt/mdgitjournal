mdgitjournal

A minimal markdown journal for macOS, Linux and iPhone, kept in plain git.

Every entry is a plain .md file in an ordinary git repository, so you have version history from the first keystroke, offline and without an account. Write in a quiet serif view or in plain source; both are the same text, and the app never changes a byte you didn't touch.

To use more than one device, connect a GitHub repository of your choice. Syncing is two buttons, Pull and Commit & Push, and nothing is committed or pushed until you say so. When edits collide, both versions are kept.

  • No database, no front matter, no hidden metadata.
  • No telemetry, no analytics, no server. Privacy.
  • One small Rust binary and the system WebView.

Get it

  • Download for macOS (.dmg) or Linux (AppImage, .deb, .rpm).
  • Arch Linux: mdgitjournal or mdgitjournal-bin from the AUR.
